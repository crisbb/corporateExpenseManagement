Python 报销流程：
1. 员工在 OA 系统填写报销申请
2. 附上发票照片和消费明细
3. 直属主管审批
4. 财务部门复核
5. 审批通过后 3 个工作日内打款

请假制度：
1. 提前一天在 OA 提交请假申请
2. 1天以内由组长审批
3. 1-3天由部门经理审批
4. 3天以上需要总监审批
5. 年假每年 10 天，病假需要医院证明

技术栈说明：
后端使用 Python + FastAPI
前端使用 React + TypeScript
数据库使用 PostgreSQL
缓存使用 Redis
消息队列使用 RabbitMQ
部署在阿里云 ECS 上

加班制度：
工作日加班需提前向主管报备
加班超过 3 小时可申请调休
调休需在 30 天内使用
法定节假日加班按三倍工资计算

会议室预订：
所有会议室需提前在 OA 系统预订
会议室按部门划分，优先本部门使用
外部会议需提前 3 天申请
会议室使用需提前 10 分钟到场

IT 支持：

密码重置可自助或联系 IT
外部访客需提前报备网络

上班时间 9:30-18:30

每月迟到 3 次以内免扣
