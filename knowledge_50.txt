公司基本信息：
公司全称：星辰科技有限公司
成立时间：2018年3月
总部地址：杭州市余杭区文一西路969号

主营业务：企业级 SaaS 解决方案

办公时间制度：
标准工作时间：周一到周五 9:30-18:30
弹性工作制：最晚 10:00 到岗，最晚 19:30 离开
午休时间：12:00-13:30
周六周日休息，法定节假日按国家规定执行
弹性工作需提前告知团队，不可连续三天弹性

报销制度：
员工需在费用发生后 30 天内提交报销申请
报销流程：OA 填写申请 → 附发票照片 → 直属主管审批 → 财务复核 → 打款
审批通过后 3 个工作日内打款至工资卡
单笔 5000 元以下主管审批即可
单笔 5000 元以上需部门经理二次审批
单笔 20000 元以上需总监审批
发票丢失需注明原因并附消费明细，主管签字确认
交通报销：地铁公交实报实销，打车需附行程单
餐费报销：客户招待人均不超过 200 元，需附人员清单

请假制度：
提前一天在 OA 系统提交请假申请
1 天以内由直属组长审批
1 天到 3 天由部门经理审批
3 天以上由分管总监审批
7 天以上需 CTO 审批
年假：入职满 1 年 10 天，满 3 年 15 年，满 5 年 20 天
病假需二级以上医院诊断证明，连续病假超 7 天需提交病历
事假每年累计不超过 10 天，事假期间不计薪
婚假 3 天，产假 158 天，陪产假 15 天
丧假 3 天，需提供相关证明
请假期间需指定工作交接人，确保业务不中断

考勤管理：
打卡方式：企业微信打卡或人脸打卡
每月迟到 3 次以内（每次 30 分钟以内）免扣
第 4 次起每次扣 50 元
连续旷工 3 天视为自动离职
外勤需提前在 OA 申请外勤打卡
出差期间无需打卡，以出差审批单为准
考勤异常需在 48 小时内提交补卡申请
每月 5 日公示上月考勤，有异议 3 日内申诉

一线城市（北上广深）住宿标准 600 元/晚
二线城市住宿标准 400 元/晚
三线城市及以下住宿标准 300 元/晚
机票：提前 7 天预订经济舱，总监及以上可订商务舱

出差补贴：100 元/天（含市内交通和餐费）
出差报销需在返回后 7 个工作日内提交

技术栈说明：
后端：Python + FastAPI，微服务架构
前端：React + TypeScript + Ant Design
数据库：PostgreSQL 15 + Redis 7（缓存）
消息队列：RabbitMQ（异步任务）+ Kafka（日志流）
搜索引擎：Elasticsearch 8
对象存储：阿里云 OSS
CI/CD：GitLab CI + ArgoCD
监控：Prometheus + Grafana + AlertManager
日志：ELK（Elasticsearch + Logstash + Kibana）
容器编排：Kubernetes（阿里云 ACK）
网关：Kong API Gateway

代码规范：
Python 代码遵循 PEP8，使用 Black 格式化
Commit 信息格式：type(scope): description
type 包括：feat, fix, docs, style, refactor, test, chore
功能开发必须在 feature 分支，禁止直接推 master
代码合并需至少 1 人 Code Review 通过
单元测试覆盖率不低于 80%
接口变更需同步更新 Swagger 文档
数据库迁移使用 Alembic，禁止手动改表

Git 工作流：
主干分支：main（生产）、develop（开发）
功能分支：feature/功能名
修复分支：hotfix/问题描述
发布分支：release/v版本号
合并前必须解决所有冲突，禁止 force push
主干分支保护：需 2 人 approve 才能合并
每个 Sprint 结束打 tag 标记版本

安全制度：
密码要求：至少 12 位，包含大小写 + 数字 + 特殊字符
密码有效期：90 天，不可与最近 5 次重复
连续 5 次密码错误锁定账户 30 分钟
双因素认证：VPN 和敏感系统登录必须开启
外部访客需提前报备，佩戴访客工牌
禁止在公共设备上保存公司密码
禁止将公司代码上传到公开 GitHub
敏感数据导出需 CTO 审批
每月进行 1 次安全扫描，高危漏洞 24 小时内修复
